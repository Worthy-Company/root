# Particular Things

*Early-stage app idea — not being built yet. Kept here so the thread isn't lost between conversations.*

## What it is

A platform Nate has in mind for distributing things — connects to his decluttering instinct of "find a home for it, don't send it to a landfill" rather than pressuring himself (or others) to discard things. Working name: "Particular Things."

## Job to be done (draft)

When I have a particular thing I no longer need, I want to find it a good home instead of sending it to a landfill, so that it gets used by someone who actually wants it.

## User story (draft)

As someone decluttering, I want to describe a specific thing I no longer need and have something help match it to someone who wants it, so it doesn't end up as waste.

## Status

Not ready to build. Revisit when it's time to get focused on this — no rush. This note exists so the connection to earlier conversations (device management, house decluttering) carries forward.
